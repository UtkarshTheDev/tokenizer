# Why Byte-Level BPE?

## The Problem with Regular BPE
- Vocab contains words/subwords from training data
- Unknown words → OOV error or <unk> token
- Languages with different alphabets:怎么处理?

## The Solution: Byte-Level
- Start with 256 UTF-8 BYTES (not characters!)
- Work directly at byte level
- Emoji 🌟 = 4 bytes [240, 159, 140, 158]
- Chinese 你 = 3 bytes [228, 189, 160]

## Key Insight
- Every possible text can be represented as bytes
- Every byte is already in vocabulary (0-255)
- NO unknown tokens ever!

## Models Using Byte-Level
- GPT-4: cl100k_base (200K vocab)
- GPT-3.5: r50k_base (50K vocab)
- Llama 3: New BPE with extended vocab
- Mistral: BPE on bytes

## Example
Text: "hello 🌍"
- Regular BPE: ["hello", "<unk>"] or error!
- Byte-Level BPE: ["he", "llo", " ", "ð", "ŏ", "8", "?", "?"]
