# Key concepts:

## Why Pre-tokenization?
- Prevent tokens from crossing word boundaries ("hello world" shouldn't become "hello" + "world")
- Keep punctuation attached correctly
- Handle numbers, URLs, code as units

## GPT-2 Pre-tokenizer Example
"Hello, world! It's 2024." → 
[('Hello', 0-5), (',', 5-6), ('▁world', 6-12), ('!', 12-13), ("▁It's", 14-18), ('▁2024', 19-23), ('.', 23-24)]

## Key Pattern Rules
- Whitespace before punctuation: "hello !" → "hello", "!"
- Contractions: "don't" → "don", "'", "t"
- Numbers: Keep sequences of digits together
- Special: Leading whitespace becomes "▁" character
